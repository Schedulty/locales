# Security policy

The locale files are plain text, but the bot reads trigger and pattern phrases from them for every incoming message.
If a change to these files could make the bot misbehave, slow down, or show something it should not, please report it
privately rather than in a public issue:

- GitHub: **Security** tab → **Report a vulnerability**;
- email: locale@schedulty.ru.

We reply within a week. Only the latest published version gets fixes.
